# Three-Step Autonomous Construction Evidence

This test is a controlled proof of the platform-weaving contract.

Order:

1. `platform.user-management`
2. `platform.organization-model`
3. `platform.security-layer`

For each capability the evidence must contain Engine, focused test, and documentation. Dependencies must exist before the next capability is admitted. Unknown capabilities are rejected.

Completion is not inferred from a successful function return alone; repository artifacts and dependency evidence are required.
