# HooshyarOS Project Constitution

## Purpose
Why this platform exists.

## Core Principles
- Human First
- Science Before Opinion
- Explainable AI
- Governance by Design
- Continuous Learning
- Adaptive Planning
- Resilience by Design
- Ethical Competition
- Knowledge Persistence
- No Single Point of Failure

## Architecture Rules

### Rule 1
Every decision must be explainable.

### Rule 2
Every engine must continue working if another engine fails.

### Rule 3
No individual may become a critical dependency.

### Rule 4
Every plan is editable.

### Rule 5
Every recommendation includes uncertainty.

### Rule 6
Every important decision is challenged before execution.

### Rule 7
Knowledge belongs to the platform, not individuals.

### Rule 8
Automation never overrides ethics.

## Golden Question

Does this increase long-term resilience?
