----------------------------------------------------------------
1. DISCOVERY (current-state scan)
----------------------------------------------------------------
`scripts/cline-runtime-evidence-collector.cjs` marks the `android-release`
qualification cell PASS when `.hooshyar/android-acceptance-success.json` is
present, commit-current and `status: PASS` (cline-runtime-evidence-collector.cjs:25,31,53).

That artifact was NOT produced by the Android acceptance harness. It was
hand-authored by the CI workflow step in `.github/workflows/final-product-factory.yml`:

    cat > .hooshyar/android-acceptance-success.json <<EOF
    { "type": "ANDROID_PRODUCT_ACCEPTANCE_SUCCESS", "status": "PASS",
      "commit": "$(git rev-parse HEAD)",
      "acceptance": ["apk-build","emulator-install","launcher-start",
                     "process-alive","main-activity-visible"] }
    EOF

while `scripts/android-product-acceptance.sh` (the owner that runs the real
adb install / launch / liveness / foreground checks) produced no evidence at
all. A hard-coded marker list asserted by the caller is exactly the
marker-only evidence the governance/K3 evidence rule forbids
("Hard-coded method markers are hints only and must never be the sole source
of truth for capability completion") and it decouples the artifact from the
checks that justify it.

----------------------------------------------------------------
2. ROOT CAUSE
----------------------------------------------------------------
Evidence ownership was inverted: the CI workflow (a caller) authored the
qualification artifact for the `android-release` cell instead of the
canonical Android acceptance harness that performs the verifications.

----------------------------------------------------------------
3. REPAIR (one coherent root cause -> one bounded change set)
----------------------------------------------------------------
NEW  scripts/android-acceptance-evidence.cjs
     Canonical owner of the artifact. Commands: begin | record <step> |
     complete | fail <reason> | verify. Fail-closed:
       - begin clears any previous result (no stale PASS can be inherited);
       - record rejects unknown steps and refuses to append to a finished run;
       - complete refuses until all 8 required real steps were recorded;
       - fail deletes the artifact so no success survives a failure;
       - verify rejects missing / non-PASS / incomplete / unbound artifacts.
     Env override HOOSHYAR_ANDROID_EVIDENCE_PATH isolates the artifact in tests.

MOD  scripts/android-product-acceptance.sh
     Now emits its own evidence: `begin`, one `record` after each real check
     (apk-present, device-online, android-booted, package-manager-ready,
     apk-installed, launcher-start, process-alive, main-activity-visible),
     then `complete`. An ERR trap calls `fail`, so an interrupted/failed run
     leaves no PASS artifact. Adds an explicit pre-flight APK existence check
     and env-overridable APK/NODE for device-free verification.

MOD  .github/workflows/final-product-factory.yml
     Removed the hand-authored heredoc evidence step. Replaced with a
     fail-closed validation of the harness-produced artifact:
        run: node scripts/android-acceptance-evidence.cjs verify

NEW  Backend/HBOS/test/AndroidAcceptanceEvidence.test.ts
     Focused behavioral suite (real subprocesses, real filesystem, no mocks).

No engine, registry, lifecycle, memory, knowledge, decision, assistant,
project-pilot, reaction, health-monitor, boot, persistence, observability,
security or tenant-isolation implementation was modified. No capability
reordered/added/removed. No criterion weakened. No completion flag changed.

5. HONEST LIMITATIONS
----------------------------------------------------------------
- No physical Android device / emulator / JDK / Gradle / Android SDK exists on
  this host (B4 = BLOCKED_ENVIRONMENT). The real device acceptance was NOT run

  job (emulator) to pass; this knot does not and cannot substitute for it.

  copy that is separate from the canonical harness and does not emit evidence.
  Recorded, not selected (no evidence-consumer impact); a future bounded
